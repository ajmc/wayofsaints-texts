## Method

Each volume has one scan, so the text is that scan's OCR cleaned, not voted between scans.

## Known limits

- **OCR errors remain.** About 0.68% of lower-case words are not in a spelling dictionary. That figure is an upper bound: it also counts British spellings, Latin and proper names. The text has been corrected by machine, not proofread by a person; corrections are welcome.
- Only the opening chapters of each season are included, not the whole work.

About 52,990 words.
